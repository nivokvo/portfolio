## Проекты

### 1. Мониторинг сайтов с ИИ-классификацией (2026, работает 24/7)
**Задача:** на сайте объявлений сотни новых записей в день, нужные вручную не найти.
**Решение:**
- Python-сборщик каждую минуту забирает новые объявления по 20+ поисковым запросам и отсекает лишнее regex-фильтрами.
- Двухступенчатая классификация: быстрая модель (Gemini) делает первичный отсев, затем Claude оценивает по подробной рубрике и пишет краткое обоснование.
- Резерв в облаке: Cloudflare Worker (cron, KV) продолжает мониторинг, когда ноутбук выключен, тяжёлые задачи уходят в GitHub Actions.
- Результаты приходят карточками в Telegram-бот.
**Результат:** за две недели классифицировано ~1000 объявлений, точность отсева проверена выборочной перепроверкой. По логам правятся фильтры и рубрика.
**Стек:** Python, Playwright, Cloudflare Workers + KV, GitHub Actions, Gemini, Claude, Telegram Bot API.

### 2. Бот «Билет БЖД» — [@bilet_bzd_bot](https://t.me/bilet_bzd_bot)
**Задача:** билеты на популярные поезда быстро разбирают, места появляются внезапно.
**Решение:** Telegram-бот и Mini App: поиск станций с исправлением опечаток, выбор поезда и типа вагона, отслеживание мест с уведомлением, варианты с пересадкой, подбор лучшего варианта.
**Результат:** живые пользователи, проверка отслеживаемых маршрутов примерно раз в минуту.
**Стек:** JavaScript, Cloudflare Workers, D1 (SQLite), Telegram Mini Apps, Workers AI.

### 3. Парсер Wildberries и Ozon
Поиск товаров, карточки, цены, отзывы, данные о продавце; выгрузка в JSON и таблицы вместо ручного сбора.
**Стек:** Python, headless-браузер, JSON/CSV, Google Таблицы.
